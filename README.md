# AwareNet — Security Awareness Simulation Lab

AwareNet is a professional, consent-first security awareness tool designed to simulate social engineering and media-access phishing scenarios in controlled, educational environments.

## Disclaimer
This tool is for educational purposes and authorized security audits ONLY. It features built-in transparency mechanics to ensure ethical use.

## To install do the following command :

1 : Install python if not install

2 : run pip install -r requirements.txt
    if it does not works try : python -m pip install -r requirements.txt

3 : finally run the file corresponding to your system : 
    linux and android : start_termux.sh
    windows : start_windows.bat
